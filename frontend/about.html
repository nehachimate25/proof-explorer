About

Mathematical Proof Verification and Proof Method Explorer, a Discrete Mathematics project for B.Tech Information Technology.

Purpose

The project helps students understand mathematical reasoning. Instead of only answering true or false, it shows each logical and algebraic step, says why the step is valid, and is honest when it cannot verify something.

What it covers

  • Logic: truth tables, tautologies, equivalence
  • Propositions: logical form of a statement
  • Proof techniques: direct, contrapositive and contradiction
  • Mathematical induction: base case, hypothesis and step

How it is built

The pages you are looking at are plain HTML, CSS and JavaScript. They talk to a Flask backend written in Python using the browser’s fetch function. All the mathematics (truth tables, algebra checks, induction arithmetic with exact fractions) runs in that Python engine, and saved proofs go into a SQLite database. Nothing is sent to an outside service.
