Proof Explorer

A small lab for Discrete Mathematics. Type a statement and see which proof methods suit it, then read the proof one step at a time. Every result is checked by the Python backend, not guessed.

The kind of proof you will see

Claim. If n is even, then n² is even.

  1. Assume n is even.
  2. Then n = 2k for some integer k.
  3. So n² = (2k)² = 4k² = 2(2k²).
  4. 2k² is an integer, so n² is even.

Open this statement in the Proof Explorer to step through it with the reason for each line.
