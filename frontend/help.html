Help

Short answers to the questions that come up most when you are starting with proofs.

Questions

What is a proposition?

A statement that is either true or false, but not both. For example, “n is even” is a proposition once we know which n we mean.

What is an implication?

The statement P → Q means “if P is true, then Q is true”. It is false in only one case: when P is true and Q is false.

What is a direct proof?

You assume P, use definitions and algebra, and arrive at Q.

What is a proof by contradiction?

You assume the statement is false and follow the consequences until something impossible appears. Since the assumption leads to nonsense, the statement must be true.

What is the contrapositive?

The contrapositive of P → Q is ¬Q → ¬P. It is logically equivalent to the original, so proving one proves the other. It is not the same as the converse, Q → P, which can be false even when P → Q is true. You can check this on the Logic page.

What is mathematical induction?

A way to prove that a statement P(n) is true for every n from some starting value. You prove a base case and then prove that P(k) leads to P(k+1).

What is a base case?

The smallest value of n, checked directly to confirm the statement is true there.

What is an inductive hypothesis?

The assumption that the statement is true for n = k. It is only used inside the inductive step. It is not a proof on its own.

What is an inductive step?

The argument that if the statement is true for n = k, then it is also true for n = k + 1.

What the result labels mean

  • Verified The backend checked every step of the proof.
  • Supported The statement is recognised and explained, but a full proof is not generated.
  • Needs review The statement is only partly understood, so the backend does not claim a result.
  • Invalid The input is empty, badly formed, or not a mathematical statement.
  • Disproved The statement is false. A counterexample is shown.
